# iRobot Create3 Exploration by CROB-ART 

## 1. Project Overview

This project focuses on the development and experimentation of the
iRobot Create3 mobile robot using ROS 2 and a Raspberry Pi-based
computing platform.

The work includes establishing communication between the Create3,
Raspberry Pi, and development computer; interfacing with the robot
through ROS 2; implementing motion control; integrating sensors; and
developing a foundation for future autonomous robotics experiments.

---

## 2. Objectives

The primary objectives of this project are:

- Establish reliable communication between the Create3 and Raspberry Pi.
- Configure and operate the robot using ROS 2.
- Understand the ROS 2 interfaces provided by the Create3.
- Implement and test robot motion control.
- Acquire and process robot state and odometry information.
- Integrate a camera and other sensors.
- Develop closed-loop control systems.
- Establish a platform for future perception, navigation, and autonomy
  experiments.
- Eventually 3d map a space in our college premises and create a dataset for future training and use.
